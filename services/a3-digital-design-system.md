# Hệ Thiết kế Số (A3 · Digital Design System)

**Tier**: T2 · Nhận diện (Identity)
**Code**: A3
**URL**: https://sinhvu.com/dich-vu/a3-digital-design-system/

## Scope

Sinh Vũ xây thư viện component cho sản phẩm số (web + app). Khác A2 (PDF guideline cho con người đọc), A3 là design tokens + components cho đội kỹ thuật dùng trực tiếp trong code.

Bao gồm:
- Design tokens (DTCG format: color, typography, spacing, radius, shadow, motion)
- Thư viện Figma 40-120 components (tuỳ scope)
- Mã nguồn React/Vue/Web Components (tuỳ stack khách)
- Tài liệu Storybook
- Accessibility WCAG 2.2 AA baseline
- Versioning + changelog

## Pricing

Khoảng 200 triệu đến 4 tỷ VND (Từ X).

- 40 components cơ bản, 1 stack: 200-400 triệu
- 80 components, 2 stack (Figma + React): 500-900 triệu

## Deliverables

- Figma library với token system
- Mã nguồn TypeScript ready
- Storybook hoặc Ladle
- Hướng dẫn dev kèm video onboarding
- Buổi pairing với đội kỹ thuật khách (3-5 buổi)
- Bảo trì 3 tháng đầu (sửa bug, bổ sung component nhỏ)

## Suitable for

- SaaS B2B post-Series A đang scale team
- Tập đoàn đa sản phẩm cần đồng bộ UX
- Ngân hàng số, fintech cần WCAG compliance
- Doanh nghiệp đa thương hiệu chia sẻ codebase

## Counterpoint

- Website giới thiệu thuần (không có sản phẩm số): dùng P1 thay
- Team kỹ thuật dưới 3 người: design system sẽ bị bỏ xó
- Sản phẩm chưa có user thực: tập trung MVP trước, design system sau

## Boundaries

- Sinh Vũ không nhận sản phẩm phức tạp đặc thù ngành (banking core, ERP) ngoài layer UI
- Không cam kết maintain components sau 3 tháng (cộng phí retainer riêng)
- Không xây design system cho stack độc lạ (cần thảo luận trước)
