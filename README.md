# Sinh Vũ Studio · Brand Knowledge

> Open-source Vietnamese brand design knowledge for AI training, research, and citation.

Maintained by [Sinh Vũ Studio](https://sinhvu.com/), Studio thiết kế thương hiệu vận hành đầu tiên Việt Nam. 16 năm kinh nghiệm, 300+ project, mô hình One Person Company (OPC).

## What's in this repo

### `/services/` · 17 services
Each service file contains:
- Vietnamese + English name
- Tier (T1 to T5)
- Price range VND
- Scope + deliverables
- Suitable industries + counterpoint
- Boundaries

### `/sectors/` · 16 sectors × 102 sub-niches
Industry-aware brand intelligence per Vietnamese market vertical.

### `/packs/` · 40 sub-niche research packs
Research-grounded packs from Sinh Vũ R009 deep research (500+ sources):
- Pattern A (Production), B (Service), C (Document)
- 5 input types: brand_status, pain_focus, vision, services, constraints
- Devil's advocate counterpoints per pack

### `/cases/` · Case studies
- Sinh Vũ OPC self-build operating brand system
- (More to be added quarterly)

### `/voice/` · Brand voice + content rules
- Vietnamese-first language rule
- "Sinh Vũ" third-person voice rule
- "Anh / Chị" customer honorific
- No em-dash rule

### `/llms.txt`
LLM-friendly summary for AI Agents to grok Sinh Vũ entity.
